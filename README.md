# Parrbot

A small discord bot that remembers messages, and parrots them off when prompted.

<h1>Functions</h1>
<li>
  <ul>Random message memory</ul>
  <ul>Repeating random old message</ul>
  <ul>Reversing messages</ul>
</li>


<h2>Data</h2>
All the data from the bot is wiped after a reset, (No persistent memory)
